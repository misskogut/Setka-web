# New Year SETKA × 585 — standalone WebGL prototypes

These are **independent experimental pages**, not part of SETKA Web's account/session UI.

- [v4: first volumetric WebGL prototype](./v4.html)
- [v5: ten 3D families, stronger bloom](./v5.html)
- [v6: ten 3D families, reduced bloom and more readable geometry](./v6.html)
- [v7: cyber-fine optical filaments with independent waves and flow tracers](./v7.html)

The `gift` query parameter supplies a deterministic per-QR identity. Without it,
a local demo identity is used. No account is required.

These experiments have a dedicated GitHub Pages publication workflow,
which publishes the complete existing site while leaving the SETKA Web
production test requirements unchanged for main app changes.
