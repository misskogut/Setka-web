# SETKA Foundation 0.1

## Статус
Первая чистая вертикальная версия после остановки перегруженной Diamond-линии.

Foundation не продолжает UI Diamond 0.8.x. Diamond сохраняется как архив инженерных идей и истории, но не является родителем интерфейса Foundation.

## Закон версии
Foundation 0.1 считается стабильной только когда одновременно выполнены две проверки:

1. автоматический Front ↔ API ↔ DB smoke зелёный;
2. Президент вручную протыкал пользовательский фронт и Президентскую админку и подтвердил, что всё читается и работает.

Новая Foundation 0.2 создаётся только как Foundation 0.1 + явная небольшая дельта. Foundation 0.1 после стабилизации не переписывается.

## Полная пара 0.1

### Пользовательский фронт
`foundation-user-v01.html`

Функции только:
- вход: SETKA ID + личный ключ;
- личный кабинет;
- вкладка «Паттерны»;
- 2 канонических паттерна: `tentacle-orbit` и `dandelion`;
- открыть паттерн;
- поставить / убрать ♥;
- состояние ♥ хранится на сервере и переживает новый вход.

В 0.1 намеренно НЕТ:
- жестовой настройки паттерна;
- сообщества;
- заметок;
- Cruise;
- рекомендаций;
- состояния;
- аналитических интерпретаций;
- Flow / штаб-квартиры / архитектурного CAD.

### Президентская админка
`foundation-admin-v01.html`

Функции только:
- Президентский вход;
- Пользователи;
- Паттерны;
- Синтетические пользователи;
- создать обычного пользователя и получить SETKA ID + личный ключ;
- видеть открытия паттернов;
- видеть текущее состояние ♥;
- видеть последние события;
- видеть browser-runs синтетиков;
- тихая запись пути Президента через TRACE без canvas, точек и линий.

### Backend
Edge Function: `setka-foundation-v01@1`

Закрытая схема: `foundation`.

Канонические факты 0.1:
- profile / identity relation;
- pattern registry;
- pattern open event;
- current favorite relation;
- synthetic browser run.

SETKA ID не является паролем. Обычный пользователь получает отдельный личный ключ. Синтетические пользователи имеют отдельный ограниченный test-only login route и не получают привилегий.

### Синтетики
Первые 5 существующих персон подключены к Foundation:
- Мира — исследователь;
- Макс — спринтер;
- Лена — коллекционер;
- Илья — скептик;
- Соня — привычный пользователь.

Они используют тот же пользовательский HTML, те же кнопки и тот же Foundation API. Их события всегда имеют `synthetic=true` и не смешиваются с обычными пользователями.

GitHub Actions запускает browser-run примерно раз в час. Поведение в 0.1 ограничено доступными действиями: открыть паттерн, вернуться, поставить/убрать ♥. Более богатое характерное поведение добавляется только тогда, когда соответствующая функция реально появится во фронте.

## Тесты

`foundation-v01-smoke.mjs` проверяет:
1. synthetic login;
2. ровно два паттерна;
3. открытие паттерна;
4. toggle ♥;
5. новый вход той же сущностью;
6. сохранение ♥ на сервере;
7. возврат состояния после теста.

`foundation-v01-synthetic-runner.mjs` регулярно гоняет всех пяти synthetic actors через реальный browser front.

JS runtime проходит `node --check` до browser smoke.

## Release boundary
Foundation 0.1 пока Black Box / Preview и НЕ заменяет публичный `public-new-chat-v1.1`.

Публичный Production может быть изменён только отдельным явным решением Президента после ручной проверки пары.

## Research pencil
Карандаш — инструмент взаимодействия Президента с ассистентом, а не продуктовая архитектура.

Он:
- записывает pointer path / taps / scroll / текущий раздел;
- не рисует путь на экране;
- не создаёт архитектурные связи;
- после остановки принимает название и комментарий;
- сохраняется как TRACE для дальнейшего разбора в чате.
