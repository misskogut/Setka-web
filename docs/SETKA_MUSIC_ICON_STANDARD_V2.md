# SETKA Music — единый стандарт иконок v2

Иконки — самостоятельные визуальные ассеты. Состояния (серый, белый, свечение) добавляет интерфейс; они не должны быть нарисованы непосредственно в изображении.

## Какие значки заменяются через админку

- Любой музыкальный трек: загрузка изображения рядом с аудио.
- Четыре типа музыки: рука, открытый глаз, закрытый глаз, 8D — редактор категорий.
- Системные значки: верхняя нота, пятая категория «Орбиты», слушатель, восемь режимов движения, черепаха, заяц, Power — отдельная галерея в админке.

## Формат для новых системных значков

- **PNG, желательно 512×512 пикселей, прозрачный фон**. Поддерживается WebP с прозрачностью.
- Квадрат от 128×128 до 2048×2048, файл до 2 МБ.
- Только один белый контурный символ; без заливки фона, карточки, постороннего цвета, собственной тени или свечения.
- Поле безопасного отступа: ориентир ~10% с каждой стороны.
- Одна оптическая толщина штриха на всём наборе; тонкая линия с мягкими окончаниями.
- Углы файла должны быть прозрачными — проверяется перед загрузкой.
- SVG является исходным редактируемым мастер-файлом для дизайнера. Для смены **системного** значка через админку экспортируйте из него прозрачный PNG/WebP. Встроенные значки SETKA уже в SVG и остаются доступны как запасной вариант.

## Как это работает

Свойство `mask-image` берёт из загруженного изображения только прозрачность и форму. Поэтому у пользовательского значка, как и у встроенного SVG:
- неактивное состояние серое;
- активное — белое со свечением;
- изменения громкости и точки 1–3 принадлежат интерфейсу, а не изображению;
- касания, перемещение по орбитам, выбранный режим и воспроизведение независимы от смены значков.

Один файл не может сам по себе включить звук или сдвинуть орбиту: связка задаётся идентификатором трека/категории/системного слота. Заменив внешний вид, эти привязки не теряются.

## Принцип безопасного обновления

В редакторе можно загрузить другую иконку и увидеть её после серверного сохранения и обновления экрана. У системных значков есть «Вернуть исходный». Значки хранятся в отдельной таблице и не изменяют существующие паттерны.

Записи и управление музыкой продолжают работать в тестовой веб-версии по `?music=1` до отдельного согласования публичного включения.
