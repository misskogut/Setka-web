# SETKA — два режима исследования паттернов

## Продуктовое правило

В выборе запроса при запуске сессии пункт **«Просто исследую»** создаёт
сессию **exploration**, сохраняемую в общем списке сессий, но без
опросов состояния, симптомов и результата «до → после».

Остальные запросы («Расслабиться», «Сконцентрироваться» и т. д.)
создают сессию **outcome**: до/после, выбранные состояния, плановая
длительность и связанные исследовательские измерения.

Оба типа сессий одинаково учитывают фактическое время взаимодействия,
паттерны, конфигурации, повторные просмотры и заметки. Каждая заметка
должна сохранять идентификатор сессии (если он есть), паттерн и время.
Текст заметки нельзя включать в общую обезличенную телеметрию V2.

Отдельная кнопка **«Просто посмотреть»** в окне открытия плитки
**не равна** выбранному запросу «Просто исследую». Она оставлена
без изменения поведения и может создавать просмотры без sessionId.
Не создавать новую исследовательскую сессию через эту кнопку
без отдельного продуктового решения.

## Схема аналитики

- V2 pattern_exposure: одинаковый подсчёт просмотров и длительности
  для двух режимов; session_id связывает события с сессией.
- properties.session_type: outcome / exploration — только явное
  значение от клиента; нулевое значение не заменять догадкой.
- Отдельная категория unbound: просмотра без session_id.
- legacy_unknown: у исторической записи есть session_id, но тип
  ещё не подтверждён.
- Ни одна из этих категорий не должна автоматически приписывать
  старым записям «эффективность» или медицинский результат.
- V40/V41 и V2 могут пересекаться: не суммировать уникальных
  людей без проверенной схемы идентичности.

## Приёмочные сценарии

1. «Начать сессию» → «Просто исследую» → несколько паттернов →
   одна сессия exploration, история паттернов и заметка внутри неё.
2. «Начать сессию» → запрос, состояние, длительность →
   сессия outcome, оценка до/после, связанные заметки и паттерны.
3. После обновления страницы активный тип сессии сохраняется.
4. «Просто посмотреть» не превращается в исследовательскую сессию.
5. Главная исследовательской админки V6 показывает оба режима
   без переключателей; подробности находятся в карточке паттерна.
6. Проверить на реальном устройстве отправку session_type в V2,
   а также наличие сессии/паттерна у заметки. Автоматические тесты
   не заменяют эту ручную проверку.
