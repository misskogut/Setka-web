# SETKA Web / Diamond

Этот репозиторий вырос из веб-прототипа SETKA и теперь содержит несколько исторических продуктовых/админ-линий и новый Diamond-контур архитектуры.

## Если вы открыли проект с нуля

**Начните с `SETKA_START_HERE.md`.**

Это каноническая точка входа для нового ChatGPT Work / архитектурного ревью: порядок чтения, источники истины, правила холодной проверки текущего состояния и требования к следующей версии.

Ключевые документы:

- `SETKA_START_HERE.md` — холодный старт и законы системы;
- `docs/DIAMOND_ARCHITECTURE.md` — President / headquarters / access / architecture machine;
- `docs/WORK_REVIEW_PROTOCOL.md` — как Work должен проверять и улучшать следующую версию;
- `docs/DECISIONS_LOG.md` — почему приняты ключевые архитектурные решения;
- `docs/VERSION_HANDOFF_TEMPLATE.md` — обязательный след каждой существенной версии;
- `SETKA_DATA_MODEL_V1.md` — каноническая исследовательская модель данных;
- `ADMIN_VERSIONS.md` — исторические линии Standard / Evolution / Новый чат;
- `NEW_CHAT_ADMIN_VERSIONS.md` — социальная/Cruise линия.

Важно: документация — карта, а не замена проверки. Перед изменениями нужно сверять активный checkpoint, GitHub, миграции, текущую схему Supabase, Edge Functions, release pointers и security state.

## Исторический веб-прототип

Изначально репозиторий использовался как временный веб-прототип интерфейса SETKA для тестирования интерактивных кодовых паттернов.

В ранней линии были:

- библиотека паттернов;
- свайп между общей библиотекой и сохранёнными конфигурациями;
- живой Canvas-паттерн `Tentacle Orbit`;
- жестовое управление параметрами паттерна;
- цветовые режимы;
- сохранение конфигураций;
- превью сохранённых конфигураций;
- инструкция по жестам;
- возврат из геймплея в библиотеку.

Некоторые ранние прототипные данные сохранялись локально в браузере (`localStorage`). Это историческое описание и не является источником истины для современной серверной/канонической архитектуры.

Deployment исторического веб-контура: GitHub Pages via Actions.
