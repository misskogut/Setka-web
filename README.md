# SETKA Web Prototype

Временный веб-прототип интерфейса SETKA для тестирования интерактивных кодовых паттернов.

## Что уже есть

- библиотека паттернов;
- свайп между общей библиотекой и сохраненными конфигурациями;
- первый живой Canvas-паттерн `Tentacle Orbit`;
- жестовое управление параметрами паттерна;
- 9 цветовых режимов через кнопку-каплю с индикатором 1–9 точек;
- сохранение текущего состояния паттерна сердцем как отдельной конфигурации;
- превью сохраненных конфигураций;
- инструкция по жестам через кнопку-ключ;
- возврат из геймплея в общую библиотеку.

Все данные избранного в этой прототипной версии сохраняются локально в браузере (`localStorage`).

Deployment: GitHub Pages via Actions.
